# 2022~2025년 고등학생 진로 비교 자료

먼저 `학습지_작성.md`를 열어 내용을 확인하고, `career_comparison_2022_2025.png`를 학습지에 붙여 넣으세요. CSV는 한글이 깨지지 않도록 UTF-8 BOM 형식으로 저장했습니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `hope_jobs_2022_2025_raw.csv` | 연도별 고등학생 희망 직업 상위 20개, 총 80행 |
| `startup_plan_2022_2025_raw.csv` | 고교 졸업 직후 창업 계획, 총 4행 |
| `startup_interest_2022_2025_raw.csv` | 창업 관심 5단계 응답, 총 20행 |
| `career_2022_2025_clean.csv` | 전처리 후 연도별 세 지표와 CEO 순위, 총 4행 |
| `change_to_2025.csv` | 2025년과 2022·2023·2024년의 차이(%p), 총 3행 |
| `collect.py` | 공식 원문 표에서 CSV를 다시 수집하는 코드 |
| `preprocess.py` | 항목 정리, 숫자 변환, 긍정 관심 합산, 차이 계산 |
| `visualize.py` | 제출용 그래프 생성 코드 |
| `originals/` | 출처인 공식 HWPX 3개와 2025년 보고서 PDF |
| `sources_manifest.json` | 원본 다운로드 주소 및 파일 확인용 SHA-256 |

## 다시 실행하기

Python 3.10 이상을 사용합니다. 이 폴더에서 다음 순서로 실행하면 됩니다. 이미 수집된 파일을 활용할 때는 `collect.py` 실행을 생략할 수 있습니다.

```text
python -m pip install -r requirements.txt
python collect.py
python preprocess.py
python visualize.py
```

한글 그래프는 맑은 고딕, AppleGothic, 나눔고딕, Noto Sans CJK KR 중 설치된 글꼴을 자동 선택합니다. 한글이 깨지면 해당 글꼴 중 하나를 설치한 뒤 다시 실행하세요.

원본 CSV는 공식 표의 공개 집계값을 옮긴 자료입니다. 학생별 원자료는 아닙니다. 파일별 출처·원문 위치는 각 CSV에 들어 있습니다. 전처리 때 수치를 임의 수정하거나 결측치를 추정하지 않았으며, 관심 응답의 합이 반올림 때문에 100.1%가 되어도 그대로 보존합니다.

교차 확인: 2022·2023년 CEO·경영자 비율은 해당 연도 보도자료의 고등학생 열에서 확인했습니다. 창업 관심 분포는 2024년 시계열 표와 해당 연도 원문(2022년 section1 표37, 2023년 section0 표49)이 일치합니다. 2025년 값은 상세 보고서 고등학생 전체 열을 사용했습니다. `collect.py`·`preprocess.py`는 행 수, 연도별 응답 구성, 중복, 수치 범위와 원문 간 일치를 점검합니다.

팀즈 업로드는 사용자가 직접 진행해야 합니다. 제출할 때 학습지의 느낀 점은 실제 경험에 맞게 수정하세요.
