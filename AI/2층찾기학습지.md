**Step 3. 2층으로 인정할 것 / 인정하지 않을 것 기준 정하기**

- 표현들을 보면 애매한 경우가 있을 것이다. (예: "201호"를 2층으로 볼 수 있을까? "1~3층"은 2층을 포함한다고 볼 수 있을까? "1층"만 적힌 경우는?) 나만의 판단 기준을 세우고 이유까지 표로 정리해보자.

| 표현                 | 2층으로 인정?(O/X) | 이유                |
| ------------------ | ------------- | ----------------- |
| 2층, 2F             | O             | 층수를 직접 명시하고 있으므로  |
| 1층 (단독)            | X             | 1층이라고만 명시되어 있으므로  |
| 1~2층,1층~2층,(1층,2층) | O             | 층수가 2층이 포함되어 있으므로 |
| 1F~2F              | O             | 층수가 2층이 포함되어 있으므로 |
| 201호, 202호         | O             | 층수가 2층이여서 200호대임. |

**Step 4. 코드로 어떻게 판단할지 설계하기 (의사코드)**

- Step 3에서 정한 기준을 코드로 옮기려면 어떤 순서로 처리해야 할지, 코드를 쓰기 전에 말로 먼저 정리해보자. (문자열에 특정 단어가 포함되는지 확인하기, 숫자만 뽑아서 범위 비교하기 등)

> 1. 각 매장 주소 찾고 거기서 층수를 나타내는 표현 찾기

> 2. 2층, 2F처럼 2층을 직접 적으로 나타내거나 범위 안에 2층이 포함되었는지 확인

> 3. 조건을 만족하는 매장 저장, 2층 판단 근거 컬럼에 적기

**Step 5. 파이썬 코드 작성 및 실행하기**

- Step 4에서 설계한 대로 코드를 작성해서 실행해보자. 결과는 `store_address`에 더해 **왜 2층으로 판단했는지 근거를 적은 컬럼**을 포함해서 csv 파일로 저장한다.

~~~python
import pandas as pd

# CSV 파일 불러오기
df = pd.read_csv("hollys1_utf8.csv")

# 내가 2층으로 인정하기로 한 표현
floor2_patterns = [
    "2층",
    "2F",
    "1~2층",
    "1층~2층",
    "1F~2F",
    "1,2층",
    "1층, 2층",
    "1~3층",
    "1~4층",
    "2~3층",
    "2~4층",
    "B1~2층"
]

# 주소에서 2층 표현 찾기
def find_floor2(address):
    address = str(address)

    for pattern in floor2_patterns:
        if pattern in address:
            return pattern

    return None


# 판단 근거 컬럼 만들기
df["2층으로 판단한 근거"] = df["address"].apply(find_floor2)

# 근거가 있는 매장만 선택
floor2_df = df[df["2층으로 판단한 근거"].notna()]

# CSV 저장
floor2_df.to_csv("hollys_2floor.csv", index=False, encoding="utf-8-sig")

print("전체 매장 수:", len(df))
print("2층 매장 수:", len(floor2_df))
print("저장 완료!")
~~~
